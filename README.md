# Калькулятор лотерейных выигрышей («На руки»)

Программа для Windows, которая рассчитывает сумму «на руки» после уплаты НДФЛ с выигрыша в лотерею (с учётом прогрессивной шкалы от 13% до 22%).

## Фичи
- Ввод суммы с автоматическим форматированием разрядов (неразрывные пробелы) и знаком ₽.
- Прогрессивный расчёт налога согласно законодательству РФ.
- «Весёлые» подсказки при наведении на итоговую сумму (от «А хватит ли на пирожок?» до «Покупаю остров»).
- Умный инсталлятор (Inno Setup), который сам проверяет и при необходимости устанавливает .NET 10 Desktop Runtime.

## Стек
- C# / .NET 10 (WinForms)
- Inno Setup 6 (установщик)

## Как собрать
1. Установите .NET 10 SDK.
2. Соберите проект: `dotnet publish -c Release -r win-x64 --self-contained false -o publish`
3. Скомпилируйте установщик: откройте `installer\LotteryTax.iss` в Inno Setup и нажмите F9.
